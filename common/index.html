🕸️ 网络机制 ​

本节涵盖与网络生态系统的一般知识及其运作方式相关的问题

URL
与超文本和 HTTP 一样，URL 也是 Internet 的一个关键概念。它是浏览器用来检索网络上任何已发布资源的机制

📑 术语表 ​

Web 技术包含用于文档和编码的一长串行话和缩写。术语表提供了成功理解和构建网络所需的单词和缩写的定义

TCP
TCP 是一种重要的网络协议，它可以让两台主机连接并交换数据流。TCP 保证数据和数据包的传输顺序与发送顺序相同
